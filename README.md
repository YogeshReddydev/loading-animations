
# Loading Animations

A collection of **50 creative CSS loading animations**, built with HTML, CSS, and JavaScript.

Explore different loading effects, preview them live, and view or copy the prompts behind each animation.

**Live Website:** https://yogeshreddydev.github.io/loading-animations/

## Features

- 50 unique loading animation concepts
- Live animation previews
- Search and category filtering
- View and copy prompts for individual animations
- Responsive design for desktop and mobile
- Minimal monochrome animation artwork
- Clean, modern interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### 1. Clone the repository

    git clone https://github.com/YogeshReddydev/loading-animations.git

### 2. Open the project folder

    cd loading-animations

### 3. Run the project

Open `index.html` in your browser.

No build process is required.
